# Simple Python Browser

A basic web browser built with Python using PyQt6 and PyQt6-WebEngine.

## Features

- Loads web pages inside a desktop application
- URL/search bar
- Reload button
- Browser window built with PyQt6
- Page rendering with `QWebEngineView`

## Requirements

- Python 3
- PyQt6
- PyQt6-WebEngine

## Installation

Clone the repository:

```bash
git clone <repository-url>
cd <repository-folder>
```

Create and activate a virtual environment:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Install the required packages:

```bash
pip install PyQt6 PyQt6-WebEngine
```

## Running the Application

```bash
python3 main.py
```
